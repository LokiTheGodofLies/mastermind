MODULE: fsub  (modules/fsub/)
=============================
Purpose
  Force users to join required channels before they can use the bot (private chat only).

How it works
  - Global switch: config fsub_enabled (toggle in /customize -> FORCE SUB).
  - Channels (table fsub_channels) are added in /customize by ID or by forwarding a message.
    Mode "normal": user must be a member. Mode "join_request": a pending join request is enough
    (recorded by handle_chat_join_request).
  - Middleware (group -1): when channels are missing the user gets the "fsub_message" template
    with one Join/Request button per missing channel and "Try Again / Verify".
  - Admin/Owner are never blocked. /customize, /adminhelp, /id and fsub_/cust_ buttons bypass it.
  - fsub_verify callback re-checks membership and confirms or refuses.
  The bot must be an admin of every required channel to read membership / create invite links.
