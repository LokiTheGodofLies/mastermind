MODULE: start  (modules/start/)
===============================
  /start              Registers the user (first time = new user), marks the helper bot as started
                      in private chat, shows the "start" template (text, optional photo, buttons).
  /start file_<id>    Deep link from search results: delivers that file (quota rules apply).
  /start ref_<id>     Applies the referral bonus once for first-time users.
  /start helper_init  Activates a helper bot for file delivery.
Start menu buttons: Search Library, Help Menu, My Quota, Convert Ebook, Refer & Earn, Community
(if community_url is set) and, for admins, Customize Bot / Admin Help. Extra buttons added in
/customize are appended.
menu_callback_router handles: help_*, adm_sec_*, search_menu, stats_menu, start_menu, quota_menu,
bot_owner (lists the configured owner IDs).
