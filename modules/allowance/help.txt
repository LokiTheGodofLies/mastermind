MODULE: allowance  (modules/allowance/)
=======================================
Purpose
  Daily quotas for searching and requesting, admin gifts, and the referral programme.

Files
  allowance.py  Quota logic + commands /quota, /gift, /refer (alias /ref).
  referral.py   Referral rules: first-time users only, one bonus per new user, banned referrers
                rejected, self-referral rejected. Notifies both people by DM.

Commands
  /quota                       Show role, searches left and requests left (template "quota_status").
  /gift <user_id> <s> [r]      Admin/Owner. Add bonus search (and request) quota. r defaults to s.
  /refer | /ref                Show your invite link t.me/<bot>?start=ref_<id>, invite count and
                               total bonus, with a Share button.

Logic
  - Quotas reset automatically when the stored date differs from today (server date).
  - Searching is free. 1 search quota is deducted only after a file is DELIVERED
    (deduct_search_quota in search/handlers.py). 1 request quota is deducted only after the
    request card is posted to the request log. Failed actions never cost quota.
  - Admin/Owner are unlimited. Banned users can never search or request.
  - Base quota per role comes from config (search_quota_default, request_quota_default,
    promoter_quota_default, volunteer_quota_default, moderator_quota_default).
  - Referral bonus (referral_bonus_search / referral_bonus_request, default 10 each) is added to
    BOTH inviter and invitee and survives role changes (stored in bonus_* columns).

Data: mastermind_users.db tables quotas and referrals (see database/help.txt).
