MODULE: search  (modules/search/)
=================================
Commands: /search <keyword>, /searchebook <keyword>, /searchaudiobook <keyword>
(or reply to a text message with the command). Plain text in DM also searches.

Search logic
  Every word must match at least one of title, author, series, file name, keywords, description,
  caption (case-insensitive). Up to 100 matches, 8 per page, newest first. Audio = extensions
  .mp3/.m4b/.aax or category "audiobook".

Result screen buttons
  « Back / Next » pages, 📚 eBooks only, 🎧 audiobooks only, 📤 Send All (delivers the page),
  📥 quick-download buttons (first 3), 📝 Request Book (always shown, handy when nothing matches), ❌ Cancel.

Delivery (deliver_file_to_user)
  1. Daily search quota must be available. 2. If require_helper_bot_start is true the user must
  have started a helper bot. 3. The file is copied from the storage chat by a rotating helper bot
  to the posting channel AND to the user's DM. 4. Quota is deducted only if at least one copy
  succeeded. 5. The posting-channel copy is deleted after file_delete_after_seconds
  (default 120) when auto_delete_enabled, and the deletion is logged.
Callbacks: spg|, sendall|, search_cancel, noop, dl_<id>, file_dl_<id>.
Settings: storage_channel_id, posting_channel_id, helper bot tokens, file_delete_after_seconds.
