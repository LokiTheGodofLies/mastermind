MODULE: help  (modules/help/)
=============================
Purpose
  Interactive documentation inside Telegram.

Commands
  /help                 User guide with section buttons: Search, Requests, Uploads, Quota,
                        Referral, Temporary Files, Roles, Groups Help, Converter, Formatting.
  /adminhelp (/ownerhelp)  Admin/Owner only. Sections: roles, queue control, logs, indexing,
                        upload logic, user management, backup & restore. Unauthorised attempts
                        are refused and logged.

Customising
  The main screens are templates ("help", "adminhelp"): edit them from /customize without code.
  Section texts live in handlers.py (USER_HELP_SECTIONS, ADMIN_HELP_SECTIONS).
Callbacks: help_button, help_menu, help_open_admin, help_sec_*, adm_sec_* (routed by start/).
