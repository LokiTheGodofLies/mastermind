MODULE: indexing  (modules/indexing/)
=====================================
Purpose
  Turn files into searchable library entries: validate, enrich with metadata, post to the
  storage chat and save in files.db.

Files
  book_index.py    Upload handler, approval flow, global queue, /index range scan, progress card.
  book_fetcher.py  Metadata pipeline: filename parser -> Goodreads/Storytel/Audible (lib/mediagoer)
                   -> OceanofPDF, EbookHunter, Anna's Archive, Mobilism (ebooks) /
                   AudioBookBay, Mobilism (audiobooks). Author and series from the file name are
                   never lost; results are cached in memory.

Supported files
  eBooks: .epub .pdf .mobi .azw3 .djvu .cbz      Audiobooks: .mp3 .m4b .aax

Upload logic (any file sent to the bot)
  - Unsupported -> refused. Already indexed (same file_unique_id) -> reported as duplicate.
  - Volunteer / Admin / Owner -> priority queue, indexed directly.
  - Normal User / Promoter -> posted to the Index log topic with Approve/Reject buttons; only
    Admin/Owner may approve. Banned users are ignored.
  - A file sent right after /convert is claimed by the converter instead.
  - The queue handles max_index_batch files then sleeps index_sleep_seconds (defaults 10 / 10s).

/index (Volunteer, Admin, Owner)
  /index                                        wizard: forward the last message / paste link -> skip? -> confirm
  /index t.me/ch/100 t.me/ch/300  |  /index t.me/ch/100-300
  /index t.me/ch skip 200  |  skip 200-250  |  limit=10  |  --from N --to N
  Bot API bots cannot read history, so each message id is forwarded into storage, read, deleted
  again and re-posted with a metadata caption and a database row. Run it on the storage chat itself
  to rebuild a lost database. The bot must be admin in storage and a member of the source chat.
  Progress card buttons: Pause / Resume / Wait / Cancel (progress popup shows ETA).

Callbacks: idx_ctrl_*, idx_app_yes_<id>, idx_app_no_<id>, idx_wiz_*.
Settings: storage_channel_id, max_index_batch, index_sleep_seconds, community_url.
